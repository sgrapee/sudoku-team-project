# 발표 시연용 GUI

Python 기본 `tkinter`만 사용하므로 별도 GUI 라이브러리가 필요하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```powershell
python run_gui.py
```

또는 다음 명령도 같습니다.

```powershell
python gui/app.py
```

## 시연 순서

1. 오른쪽 위에서 변형 스도쿠 예제를 선택합니다.
2. 보드에 표시된 대각선·킬러·온도계·화살표 등의 제약을 설명합니다.
3. `AI 힌트`로 사람이 사용하는 논리 기법과 설명을 보여줍니다.
4. `과정 보며 풀기`로 CSP 엔진이 후보를 넣고, 제약을 전파하고, 모순이면 되돌아가는 과정을 확인합니다.
5. 느리게·보통·빠르게 중 재생 속도를 선택하고 필요하면 일시정지합니다.
6. 오른쪽에서 난이도·유일해 여부, 아래에서 탐색 노드·백트랙·실행 시간을 확인합니다.

## 숫자 색상

| 색상 | 의미 |
|---|---|
| 검정 | 퍼즐에 처음부터 주어진 고정 단서 |
| 파랑 | 사용자가 직접 입력한 숫자 |
| 주황 | 엔진이 탐색 중 임시로 시도한 숫자. 백트래킹으로 바뀔 수 있음 |
| 초록 | 탐색이 끝난 뒤 확정된 최종 숫자 |

## 단축키

| 키 | 기능 |
|---|---|
| `1`~`9` | 선택한 칸에 숫자 입력 |
| `Delete`, `Backspace` | 숫자 삭제 |
| 방향키 | 선택 칸 이동 |
| `F5` | 퍼즐 풀기 |
| `Ctrl+H` | 힌트 |
| `Ctrl+R` | 처음 상태로 초기화 |

GUI와 엔진 연결만 확인하려면 창을 띄우지 않고 다음을 실행합니다.

```powershell
python run_gui.py --smoke-test
```
