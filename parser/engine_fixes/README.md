## 결함 설명 (보고서 '방법론'용 기록)

- **A**: `model.units`가 모든 `AllDifferent`를 유닛으로 등록하고, AC-3의 hidden single이 "값 1~9가 유닛에
  반드시 한 번 나온다"고 가정했다. 9칸 묶음에서만 맞는 가정이라, 사용자 정의 영역(9칸 미만)에서는
  해가 있는 퍼즐을 "해 없음"으로 판정했다.
- **B**: `global_constraints`가 이진 아크가 있는 제약을 빼서, 킬러 케이지의 합 전파가 호출되지 않았다.
  킬러 퍼즐 풀이가 느려지는 원인이었다(예시 0.5초 → 수정 후 0.01초).
- **C**: `count_solutions`가 시간 초과 때도 0을 돌려줘서, "판정 불가"가 "해 없음"으로 보고됐다.
